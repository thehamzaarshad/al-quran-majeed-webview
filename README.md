# Al-Quran Majeed App

A lightweight Android app that opens the Al-Quran Majeed website (https://al-quran-majeed-fork.vercel.app) in a simple WebView, so you can read the Quran like a native app.

## Download
Get the latest APK from the Releases page and install it on your Android phone (Android 7.0+).

## Features
- Opens Al-Quran Majeed web app directly
- Very small APK size
- No ads, no tracking
